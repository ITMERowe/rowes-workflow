# cockpit

One dark band above the prompt that merges four rows: FLOW (the savvy-progress flow and a `×N agents` button that opens `/agents-info`), TASKS (the app's task list, with Show/Hide to list each step as ✓ done, ◐ in progress or ○ pending), SESSION (ponytail's session cost with Review and Audit buttons) and USAGE (ribbon's plan usage and cache state). It needs the savvy-progress, ponytail and ribbon plugins; a row whose plugin is missing is left out.

## Install

```
/plugin install cockpit --marketplace <owner>/rowes-workflow
```

The full setup is in the [repository README](../../README.md).
